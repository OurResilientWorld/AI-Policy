# AI Policy

Evidence-led AI policy research from Our Resilient World.

This repository publishes reader-ready derivatives only after source filtering, fidelity review,
Product Owner acceptance and human transfer. Working records, credentials, personal information and
unpublished evidence are not part of this repository.

## Published research

- [Case study 01 — Australia, AI, jobs and entry/re-entry work to 2035](research/ai-jobs/) — series
  result and a bounded Report 1 extract.

The GitHub Pages site provides the primary reader journey through each question, result, limitation
and retest route.

## Contribute

Use the repository issue forms to propose a correction, submit new evidence, outline a research
proposal or report an accessibility barrier. Issues are public: do not submit confidential,
sensitive or personal information. See [CONTRIBUTING.md](CONTRIBUTING.md).

## Governance

A contribution does not automatically change a finding. Material changes return to evidence review
and Product Owner acceptance. Published changes are versioned and visible in Git history.
